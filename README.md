# 小程序测试

小程序测试（wx-check）是搭配微信开发者工具使用的 AI skill，用来检查小程序是否写对、显示正常、操作有效，以及完整使用流程是否顺畅。

它让 AI 理解当前小程序的页面和功能，实际操作并核对结果，完成四类测试：

1. **代码测试——程序有没有写对。** 检查代码、编译、运行和开发者工具中的诊断，逐条解释错误与告警。
2. **UI测试——界面显示正不正常。** 检查不同机型和分辨率下的布局、文字截断、重叠与遮挡，并查看截图判断实际显示效果。
3. **点击测试——按钮点了有没有反应。** 实际点击按钮、菜单和页面入口，确认响应是否符合预期。
4. **流程测试——像真人一样用一遍，看顺不顺。** 识别小程序里的用户任务，从实际入口操作到最终结果，确认保存、修改、删除、导出等功能是否真正完成。

每项测试单独出报告，先用普通人能看懂的话说明发现了什么、有什么影响、哪些应该修复，再附结果证据和没测到的部分。需要修复时，在用户允许的范围内修改，并重新测试相关结果。
