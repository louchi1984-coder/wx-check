# 小程序测试

让 AI 搭配微信开发者工具，检查小程序的代码、界面、按钮和完整使用流程，并给出看得懂、有证据的测试报告。

小程序能编译、能打开之后，还需要确认各个功能能正常使用。`wx-check` 提供四类测试的方法与工具，让 AI 根据当前项目识别检查目标、实际操作、核对结果，再说明哪些问题应该修复。适用于本地原生微信小程序工程。

## 可以检查什么

| 测试 | 要回答的问题 | 具体检查 |
| --- | --- | --- |
| **代码测试** | 程序有没有写对？ | 配置与资源、编译错误、调试器告警、失败请求，以及构建、问题、输出、代码质量等诊断；逐条解释异常的含义与影响 |
| **UI测试** | 界面显示正不正常？ | 不同屏幕下的截断、重叠、遮挡和布局；小、中、大各两款精测，其余机型做最小必要检查，并关注折叠展开宽屏 |
| **点击测试** | 按钮点了有没有反应？ | 实际点击导航、按钮、菜单等入口，核对页面变化、提示和状态响应，包括需要先打开的弹层与条件入口 |
| **流程测试** | 像真人一样用一遍，顺不顺？ | 先识别完整用户任务，再从真实入口操作到最终结果，例如填写、保存、修改、取消或导出，并确认数据与产物是否正确 |

可以只选一项，也可以全部检测。全部检测默认按 **代码 → 点击 → 流程 → UI** 执行；每项先交报告，再开始下一项。

## 怎么开始

需要准备：

- 本机微信开发者工具，以及要检查的小程序工程。
- 支持加载 skill、执行本机命令和读取图片的 AI 工具；不限于某一个 agent。
- 运行辅助脚本时，需要 Node.js 22 或更新版本。安装位置与调用方式按当前机器发现，包含 macOS 和 Windows 的说明。

1. 从 [最新版本](https://github.com/louchi1984-coder/wx-check/releases/latest) 下载 `wx-check.zip`。
2. 解压，将完整的 `wx-check` 文件夹放到所用 AI 工具的 skills 目录，按该工具的方法加载。
3. 告诉 AI 工程路径和要做的测试，例如：

   > 使用“小程序测试”检查这个工程：`<工程路径>`。先做代码测试，给我报告后，再依次做点击测试、流程测试和UI测试。先检测并说明哪些问题应该修复，不修改代码。

执行时，AI 会先定位开发者工具、确认登录和目标工程。需要登录时，在真实开发者工具窗口中扫码；AppID 使用你确认的真实账号，没有 AppID 时引导你在工具中手动选择测试号。

涉及删除、清空或服务端写入等操作，按你允许的范围测试，并先确认数据保护与恢复办法。发现问题后，可选择只修当前测试发现的问题，或继续核对并修复完整业务；修改后须再测相关结果。

## 你会拿到什么

每项检测交付一份独立报告，开头先用普通话说明：**测了什么、发现什么、有什么影响、哪些该修、哪些还没测清。** 后面附检查明细、问题原因、修复建议及证据。

- **代码报告**：各诊断来源的检查状态，错误与告警逐条解释。
- **点击报告**：页面、实际入口、预期响应与操作结果。
- **流程报告**：完整任务清单，每个任务的最终结果或具体阻塞原因。
- **UI报告**：实际机型、页面和显示问题，附已审阅的精测截图与说明。

全部选定项目结束后，再给汇总报告。读取失败、任务未执行或图片未审阅会保留为缺口；有必查项缺证据时报告“部分完成”，不会将它算作通过。统一格式见 [报告规范](references/reporting.md)。

## 测试范围

主要使用微信开发者工具的模拟器与接口。不同模拟器机型的检查不能证明真实手机上的所有行为；需要真机、云服务权限或原生界面操作才能确认的部分，会单独说明。原生弹窗的实际操作与模拟返回值验证也分别记录。

AI 负责理解当前项目、设计步骤和判断结果；辅助脚本负责通道准备、诊断读取及重复的机型切换与截图。换工程后重新识别业务，不要求为每个项目添加专用测试驱动。

代码测试的内部面板读取、UI测试的运行中批量切机型需要本机调试通道。通道受阻时可继续独立检查，对应必查项仍须补测或报告缺口。执行细节从 [SKILL.md](SKILL.md)开始，调用方式见 [工具说明](references/tool-details.md)。

## 维护与验证

以下自检验证通用工具的协议与失败处理，不是小程序项目的检测结果；普通使用不需要先运行它们：

```sh
node scripts/debug-channel-selftest.mjs
node scripts/diagnostics-selftest.mjs
node scripts/device-live-selftest.mjs
node scripts/ui-batch-selftest.mjs
```

测试夹具在临时目录创建，发布包不含业务工程或历史测试数据。工具内部接口升级后按实际能力重新核验；具体工程和开发者工具版本的运行结果须以实测为准。
